Descripción del proyecto

Maquetación visual (sin funcionalidad) de la página principal de una tienda online, usando Bootstrap 5.3. El objetivo del proyecto es aplicar componentes de Bootstrap para lograr un diseño responsivo similar al de una tienda real.

Componentes de Bootstrap utilizados
Carousel: banner principal con 3 imágenes e indicadores de navegación.
Grid system (row / col-sm-*): distribución del cuerpo en dos columnas, categorías (col-sm-3) y productos (col-sm-9), con comportamiento responsivo (col-12 col-md-4 en los productos).
Cards: tarjetas de producto con imagen, nombre y botón.
List group: menú lateral de categorías.
Buttons: botón de carrito y botones "Agregar al carrito".
Badge: contador visual sobre el ícono del carrito.
Bootstrap Icons: ícono del carrito de compras.
