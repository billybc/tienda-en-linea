Tienda Online - Bootstrap + Fetch API

Nombre: Billy Eduardo Cardona Lopez Carné: 1890-20-15738

Descripción del proyecto

Página principal de una tienda online, maquetada con Bootstrap 5.3 y ampliada para cargar los productos de forma dinámica desde una API REST utilizando JavaScript (Fetch API), en lugar de tenerlos escritos directamente en el HTML.

Componentes de Bootstrap utilizados
banner principal con 3 imágenes e indicadores de navegación.
tarjetas de producto generadas dinámicamente (imagen, nombre, descripción, precio, botón).
menú lateral de categorías.
Opanel lateral del carrito de compras.
contador visual sobre el ícono del carrito.
ícono del carrito y del botón de eliminar producto.
